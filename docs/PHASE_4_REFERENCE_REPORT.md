# Phase 4 chemistry reference report

## Scope and conventions

- Systems: HCl–NaOH, CH₃COOH–NaOH, and NH₃–HCl.
- Temperature: 298.15 K; `Kw = 1.00 × 10⁻¹⁴`.
- Weak-system constants: `Ka(CH₃COOH) = 1.80 × 10⁻⁵` and `Kb(NH₃) = 1.80 × 10⁻⁵`.
- pH tolerance: 0.005 for CHEM-03 and 0.02 for CHEM-04.
- `Veq` is calculated independently from stoichiometry. Endpoint remains an
  indicator-derived milestone and is never substituted for `Veq`.

## Independent calculations

The HCl–NaOH and CH₃COOH–NaOH raw tables remain in
`tests/fixtures/phase1Reference.js` and
`tests/fixtures/chem03IndependentReference.js`. The NH₃–HCl table is stored in
`tests/fixtures/phase4Reference.js` and contains fixed expected values rather
than output generated by the production solver.

For 25.00 mL NH₃ 0.1000 M titrated with HCl 0.1000 M:

- `n(NH₃) = 2.500 × 10⁻³ mol`, so `Veq = 25.00 mL`.
- At half-equivalence, `pH ≈ 14 − pKb = 9.2553`.
- At equivalence, NH₄⁺ hydrolysis gives `pH ≈ 5.278`.
- At 25.25 mL HCl, diluted strong-acid excess gives `pH ≈ 3.303`.

The automated review checks every fixed pH/stage/excess row, independently
recomputes `Veq`, includes each equivalence checkpoint in a sorted curve, and
checks finite outputs and convergence.

## Discrepancies and limitations

No discrepancy exceeds the accepted tolerance. The model uses concentration
instead of activity and assumes ideal aqueous solutions. Very dilute solutions
are sensitive to water autoionisation, absorbed CO₂, and experimental error.
Reviewer/PO sign-off remains a separate project gate and is not inferred from
automated PASS results.
